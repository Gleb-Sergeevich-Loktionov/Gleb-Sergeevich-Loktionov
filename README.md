## Featured projects

Finished, working tools — each carries a **green CI badge** (its test suite runs on every push) and a complete, step-by-step setup guide in its README.

- **[voice-agent](https://github.com/Gleb-Sergeevich-Loktionov/voice-agent)** <br/> Real-time outbound voice agent: live speech-to-speech lead qualification via OpenAI Realtime protocol, state-machine dialogue flow, SIP telephony & signed webhooks. <br/><sub>`Python` · `FastAPI` · `OpenAI Realtime` · `SIP` · `WebSockets` · `Docker`</sub>
- **[caseflow-ai](https://github.com/Gleb-Sergeevich-Loktionov/caseflow-ai)** <br/> Human-in-the-loop document ingestion pipeline: automated PDF splitting, layout OCR, schema extraction, and deterministic risk routing with a web review UI. <br/><sub>`Python` · `Tesseract OCR` · `PyMuPDF` · `Docker`</sub>
- **[presales-planner](https://github.com/Gleb-Sergeevich-Loktionov/presales-planner)** &nbsp;[![CI](https://github.com/Gleb-Sergeevich-Loktionov/presales-planner/actions/workflows/ci.yml/badge.svg)](https://github.com/Gleb-Sergeevich-Loktionov/presales-planner/actions/workflows/ci.yml) <br/> Telegram bot that auto-schedules a team's tasks across people and days — respecting capacity, dependencies and deadlines — with a FastAPI web admin. Deterministic greedy solver over a critical-path graph; Claude intent parsing; text + voice task capture. <br/><sub>`Python` · `aiogram` · `FastAPI` · `PostgreSQL` · `SQLAlchemy` · `NetworkX` · `Claude`</sub>
- **[ai-redaktor](https://github.com/Gleb-Sergeevich-Loktionov/ai-redaktor)** &nbsp;[![CI](https://github.com/Gleb-Sergeevich-Loktionov/ai-redaktor/actions/workflows/ci.yml/badge.svg)](https://github.com/Gleb-Sergeevich-Loktionov/ai-redaktor/actions/workflows/ci.yml) <br/> Telegram bot that proofreads and edits Russian text — spelling, punctuation, grammar and unjustified anglicisms — in a single structured Claude call, returning a corrected file, a summary, and a full list of fixes. One-command Docker run; tokens via `.env`. <br/><sub>`Python` · `python-telegram-bot` · `Anthropic Claude` · `pandoc` · `Docker`</sub>
- **[notion-telegram-notifier](https://github.com/Gleb-Sergeevich-Loktionov/notion-telegram-notifier)** &nbsp;[![CI](https://github.com/Gleb-Sergeevich-Loktionov/notion-telegram-notifier/actions/workflows/ci.yml/badge.svg)](https://github.com/Gleb-Sergeevich-Loktionov/notion-telegram-notifier/actions/workflows/ci.yml) <br/> Notion → Telegram push notifications for teams on Notion **guest** seats, where native notifications stop working. Polls Notion, diffs snapshots, and DMs the right person on assignment or status change. `docker compose up -d`. <br/><sub>`Python` · `aiogram` · `Notion API` · `SQLite` · `Docker`</sub>
- **[SpotiDL DJ](https://github.com/Gleb-Sergeevich-Loktionov/spotidl-dj)** &nbsp;[![CI](https://github.com/Gleb-Sergeevich-Loktionov/spotidl-dj/actions/workflows/ci.yml/badge.svg)](https://github.com/Gleb-Sergeevich-Loktionov/spotidl-dj/actions/workflows/ci.yml) <br/> CLI that downloads Spotify playlists to MP3 with **correct-track matching** — you get the exact song and version you named, never a random remix or live cut — with full metadata and album art. Step-by-step setup incl. Spotify API keys. <br/><sub>`Python` · `yt-dlp` · `FFmpeg` · `Spotify API`</sub>
